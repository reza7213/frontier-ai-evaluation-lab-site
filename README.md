# Frontier AI Evaluation Lab · public showcase

Public project page by Reza Madad. The full experimental repository remains private. This repository contains only the static showcase, a deterministic demo over synthetic facts, and selected public project evidence.

Published site: https://reza7213.github.io/frontier-ai-evaluation-lab-site/

## Run locally

From this directory, run `python3 -m http.server 8000`, then open http://localhost:8000. No dependency installation is needed. JavaScript modules need HTTP rather than directly opening the HTML file. Run demo checks with Node 18+: `node --test demo.test.js`.

## Scope

The browser demo performs deterministic calculations on five fixed synthetic documents. It makes no model inference or API calls. The separate model and Python workflow results are reported with their own scopes and limitations. Data and figures are not real-company research or financial advice.

No account, tracking scripts, visitor storage, API credentials, private review history or model weights are included. Standard GitHub hosting logs are governed by GitHub.

The project brief and evidence summary describe pilot-v2 experiments run November 16, 2026. Independent human calibration and real-world validation remain open.
